5 · Inline Notes & Confirmations N1–N3 · moments, not screens

Dashed border = the note treatment (apricot-toned in the visual pass, never red). All are dismissible, none block, none repeat.

N1 — Overlap nudge“These two overlap — want me to nudge one?”  Nudge it  Leave it

Appears inline between the two overlapping blocks — only after a length change (edge-drag or typed). Pure reorders never trigger it (edges 22–23).

N2 — Boundary question“Are you sure? This will extend your day to 6:30 PM.”  Extend to 6:30  Put it back

Fires once per action when a block crosses the day's start or end. Confirm updates today's boundary; decline reverts the move (edge 24).

N3 — Backup whisper“A lot of good changes — want a backup file?”  Export  Dismiss

Appears in Rhythm after major template edits. Once per session; ignoring it has zero consequences (edge 18).
