First Run — S0

S0.1 is the big script moment; S0.2 introduces the settings-row pattern; S0.4 builds Monday on the real timeline. Then setup becomes a build-and-echo loop: repeat the day you just built onto still-empty days (S0.5, shown copying Monday to Wed + Fri) → the next consecutive uncovered weekday is offered (S0.5b: Tuesday) → building it earns its own repeat step (S0.5c) where days that already have plans rest grayed and untouchable. The loop runs until every weekday has a plan or an explicit "leave blank." Weekends never prompt but stay selectable while empty.

S0.5b — Next blank weekday (conditional). Always the next consecutive uncovered weekday — Monday went to Wed + Fri, so Tuesday is asked about first. "Build Tuesday now" opens the S0.4 editor titled Tuesday; "Leave blank" skips it guilt-free (wide open, buildable later in Rhythm) and the loop moves to Thursday. Weekends never appear here.

S0.5c — Tuesday's echo. The repeat step every built day earns. Scheduled days (Mon/Wed/Fri) and the source (Tue) rest recessed and unselectable; Thursday is chosen here, leaving nothing uncovered — the loop ends and setup moves on to S0.6. Sat/Sun remain quietly available while empty.
